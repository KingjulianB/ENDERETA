# ENDERETA

National digital addressing system for Angola — see
`ENDERETA_Business_Plan.pdf` for the full business plan.

Technical POC (Huambo district) lives in [`enderata/`](enderata/), packaged
as a Home Assistant add-on for now — see `enderata/DOCS.md` for install
and development instructions, and `enderata/CHANGELOG.md` for what has
actually been built vs. scaffolded so far.
